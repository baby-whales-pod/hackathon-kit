# LD-101: amortization schedule

Status: TODO

## Need
Add the `GET /loans/{id}/schedule` endpoint, which returns the loan's amortization schedule.

## Acceptance criteria
- Response: a list of `{ month, payment, interest, principal, balance }`, one item per month.
- Amounts are rounded to the cent.
- The `balance` of the last month is `0`.
- `404` if the loan does not exist.
- Tests added in `app/test/`, and `npm test` is green.
